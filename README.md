# My-First-Practice-Site
This is just a practice site for me to practice what I'm learning on HTML, CSS, and JavaScript. Because my website needed to be about something, I decided to create a World Explorer’s Recipe Book, where I share international recipes and communicate my love for travel. I’m not sure if that’s a good idea for a website, but this is just practice, remember.

I began with a basic HTML boilerplate, including my &lt;!DOCTYPE html&gt;, &lt;html&gt;, &lt;head&gt;, &lt;body&gt;, and &lt;footer&gt; elements. I added a &lt;main&gt; and a &lt;section&gt; for the body. I added a title &lt;h1&gt;, a subtitle &lt;h2&gt;, and a paragraph &lt;p&gt; introducing myself as Alex and explaining what the site was about. I also added an image &lt;img&gt; for the beginning (all images have alts for accessibility).

Then, I added another &lt;section&gt; with proper hierarchy (i.e., &lt;h2&gt;, &lt;p&gt;, etc.) and an unordered list &lt;ul&gt; of recipes, with an image &lt;img&gt; wrapped in a &lt;figure&gt; and &lt;figcaption&gt; element.

Finally, I added a &lt;footer&gt; with a &lt;p&gt; for the copyright.
